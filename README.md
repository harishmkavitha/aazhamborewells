# Aazham Borewells — static marketing site

A 30-page static website (plain HTML/CSS/JS, no build framework) for a Chennai
borewell drilling & cleaning contractor. Original "Core Sample" design — an
industrial-geology identity, deliberately unlike a typical blue water-company
template. Built as a **demo replica** for design purposes.

## What's here

```
aazham-borewells/
├── .nojekyll                # keep — stops GitHub Pages running Jekyll
├── index.html               # Home
├── about.html  contact.html  gallery.html  testimonial.html
├── privacy.html  terms.html  404.html
├── drilling-services.html   # drilling hub
├── cleaning-services.html   # cleaning hub
├── <20 service pages>.html   # 15 drilling + 5 cleaning categories
├── sitemap.xml   robots.txt
├── assets/css/main.css      # the whole design system (one file)
├── assets/js/main.js        # nav, dropdowns, ruler reveal, form
├── assets/img/              # logo.svg, favicon.svg, og-default.jpg
└── tools/build.py           # generator — single source of truth
```

## How to edit

**All pages are generated by `tools/build.py`.** Don't hand-edit the `.html`
files — your change would be overwritten next build. Instead:

- **Service page wording** → edit the `SERVICES` dict in `build.py`.
- **Nav / footer / menu items** → edit the `DRILLING` / `CLEANING` lists and the
  `nav()` / `footer()` functions.
- **Home / about / contact copy** → edit the matching `render_*()` function.
- **Colours, fonts, spacing** → edit the token block at the top of
  `assets/css/main.css`.

Then rebuild:

```bash
python3 tools/build.py
```

It rewrites every page (nav + footer are baked into each file as real HTML, so
the site is fully crawlable and works with JavaScript disabled).

## Before you launch — replace the demo placeholders

This is a demo. Swap these for the real business details, then rebuild:

1. **Phone number** — `SITE["tel_display"]` / `tel_e164` / `wa` in `build.py`
   currently hold a **placeholder** (`+91 98400 55123`). Use the real number so
   calls and WhatsApp reach the business.
2. **Domain** — `SITE["domain"]` is `https://www.aazhamborewells.com`. Set it to
   the real domain so `canonical`, `og:url` and `sitemap.xml` are correct.
3. **Email / address / geo** — update `SITE` (email, address line, PIN, lat/lng).
4. **Form endpoint** — the contact form `action` points at
   `https://example.com/your-form-endpoint`. Point it at a real form service
   (Formspree, Basin, etc.). Until then the form shows a friendly local
   acknowledgement and steers people to phone/WhatsApp.
5. **Gallery / photos** — the site now uses **real photos** from your image
   pack, optimised into `assets/img/photos/`. To change any picture, edit the
   selection in `tools/prepare_images.py`, re-run it, then re-run `build.py`.
   The chosen files are recorded in `tools/image_manifest.json`.
6. **OG share image** — `assets/img/og-default.jpg` is generated art; swap for a
   real photo-based share image if preferred (keep it 1200×630).
7. **Legal pages** — `privacy.html` and `terms.html` are **starting drafts**.
   Have them reviewed against the Digital Personal Data Protection Act, 2023, and
   insert the real **grievance officer** name/contact in the privacy policy
   (`[Insert name]` placeholder).

## Deploying to GitHub Pages

1. Push the folder contents to a repo.
2. Settings → Pages → Deploy from branch → `main` / `(root)`.
3. Confirm `.nojekyll` is committed (it's easy to lose).
4. For a custom domain, add a `CNAME` file with the bare domain and set DNS,
   then tick **Enforce HTTPS**.

Asset paths are all relative, so the site also works from a project subpath
(`username.github.io/reponame/`).

## Notes

- Fonts (Archivo + IBM Plex Sans) load from Google Fonts at runtime.
- The map on the contact page is a Google Maps embed; it loads in a real browser
  (it won't render in an offline screenshot).
- No cookies or analytics are wired in, so no consent banner is included. If you
  add analytics later, add a non-pre-ticked consent banner (see the DPDP notes).
